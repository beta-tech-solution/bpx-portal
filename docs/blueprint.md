# **App Name**: BPX Portal

## Core Features:

- User Authentication: User authentication via Firebase (email, phone, Gmail).
- Deposit Form: Deposit submission form, showing required amount, deposit account details, upload field for payment proof (image/PDF), and multilingual deposit instructions.
- Deposit Status: Display 'Waiting for Admin Confirmation' progress bar after submitting the deposit.
- Transfer Form: Transfer form from user wallet to 'My BPExch Account', showing balance, transfer amount, and recent transfers.
- Withdrawal Request: Withdrawal request form with amount and account details inputs, with multi-language (Urdu/English) instructions.
- Cross-Platform Support: Cross-platform development for deployment on Play Store and iOS App Store.
- Responsive Design: Clean and responsive design adaptable to both web and mobile platforms.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) for a trustworthy and professional feel.
- Background color: Very light indigo (#E8EAF6) for a calm, clean backdrop.
- Accent color: Teal (#009688) to draw attention to calls to action.
- Font pairing: 'Poppins' (sans-serif) for headers and 'PT Sans' (sans-serif) for body text.
- Mobile-first responsive design, ensuring a consistent user experience across devices.
